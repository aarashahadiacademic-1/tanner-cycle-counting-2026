# Tanner cycle counting (2026) — audited experiments

Fresh, independently executed Tanner-graph short-cycle counting experiments. This repository contains exact local BFS/DFS, a KB message-passing baseline, and single-processor interleaving of exact counting with non-backtracking inverse sampling. Historical pilot-and-cap, two-thread racing, and root-only-quantum implementations are NOT the final algorithm.

## Results

- `results/table1_exact_7runs.csv`: 10 exact-vs-KB same-target rows; both count all even lengths from g through T; seven-run medians in milliseconds.
- `results/table2_hybrid_100runs.csv`: 11 girth-only rows; Exact/KB are seven-run medians, Hybrid and MARE are means over 100 trials.
- Hybrid parameters: epsilon = 0.08, inverse-sampling target r = 101, Q = 4096 work credits, random seed 20261011.
- All 21 target rows were computed on the original fixed graph instances; exact and KB cycle counts agree. Numbers were obtained from real reruns, not copied from the manuscript. Wall-clock times may vary.

## Reproduction

From repository root with Python 3.8+ and g++ (C++17):

    python3 scripts/generate_core.py
    python3 scripts/generate_diverse.py
    g++ -std=c++17 -O3 src/exact_benchmark.cpp -o exact_benchmark
    g++ -std=c++17 -O3 src/chunk_hybrid.cpp -o chunk_hybrid
    python3 scripts/run_all.py

The fixed edge lists for 12 non-QC instances are in `graphs/`. Q410 and Q412 are deterministically generated by `scripts/generate_core.py`. Both published CSVs contain SHA-256 hashes; `scripts/run_all.py` verifies hashes before running. Graph generation is not timed; PEG generation may be slow.

## Exact per-turn credit limit, without per-operation step() overhead

The final optimized Hybrid has two atomic microtasks: a bounded BFS for one root and a bounded residual DFS for one boundary vertex x. Before starting a microtask, it checks an analytical worst-case credit bound against the remaining Q budget. Consequently, no scheduling turn exceeds Q credits, including Q412, and no partial root work is repeated. The sampler processes complete non-backtracking trials and charges 1+8g credits per trial: one root choice and eight for each of g sampled edges. Each exact BFS/DFS primitive counted by the implementation is charged one credit.

These credits are a stated cost model, not CPU instructions. For degrees/girth/quantum where the conservative microtask bound exceeds Q, the optimized benchmark fails explicitly rather than silently violating the limit; a finer-grained fallback would be required for arbitrary Q. The general RAM-model theorem is distinct from these benchmark-specific work credits. Because a branch may yield with unused budget, the observed ratio of consumed work credits to standalone exact work can be slightly over 2; wall-clock times have no uniform twofold guarantee.

## Source

- `src/bench_core.cpp`: exact and KB methods.
- `src/exact_benchmark.cpp`: simultaneous g through T counting, 7-run baseline.
- `src/chunk_hybrid.cpp`: strict-credit-Q optimized Hybrid, 7/100-run timing and error measurement.
- `scripts/generate_core.py`, `scripts/generate_diverse.py`: fixed generators.
- `scripts/run_all.py`: graph checksums, execution, count verification, and fresh JSON output.

Synthetic parity-check graphs only; not standardized LDPC code families. All measurement claims are implementation/environment dependent.
